# Superstore Sales Dashboard – Data Analyst Internship Task 2

Hi!  
This is my submission for **Task 2: Data Visualization and Storytelling** as part of the Data Analyst Internship.

---

## About the Dataset

The dataset I used is called `Superstore.csv`, which includes sales records from a fictional retail company.  
It contains information about:

- Orders (date, region, city, etc.)
- Product categories
- Sales, profit, quantity, discounts
- Customer segments

There are around 10,000 rows in total.

---

## Goal of the Project

The main goal was to explore the data and create visualizations that:
- Tell a story
- Highlight business insights
- Help decision-makers understand what’s working and what’s not

I used **Tableau** to make the charts and dashboard.

---

## What I Built

Here are the visualizations I created in Tableau:

1. **Top Categories & Sub-Categories by Sales and Profit**  
   → See which products bring the most revenue and which ones lose money.

2. **Sales and Profit Trends Over Time**  
   → Understand how performance changes across months.

3. **Profit by State (Map View)**  
   → Shows which states are profitable and which are not.

4. **Discount vs Profit (Scatter Plot)**  
   → See how heavy discounts impact profits.

5. **Segment-wise Performance**  
   → Compare how different customer types perform (Consumer, Corporate, Home Office).
